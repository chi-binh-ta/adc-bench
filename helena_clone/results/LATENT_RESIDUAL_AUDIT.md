# Helena — Residual Low-Rank Latent Structure Audit

Status: **POSITIVE INTERNAL EVIDENCE**.

System audited: canonical coherent-logit S=5 -> global G2.

## Residual objects
1. Soft probability leakage: `E[p_j | Y=k]` for `j != k`, diagonal set to zero.
2. Hard confusion leakage: `P(argmax p=j | Y=k)` for `j != k`, diagonal set to zero.

These remove the trivial self/diagonal component and ask whether systematic error flows toward shared destination directions.

## Confirmatory design
- Learn SVD right-subspace on CAL.
- Keep that subspace fixed and measure projection energy on TEST.
- Compare CAL spectral concentration, CAL->TEST transfer energy, and CAL/TEST subspace overlap against 300 null matrices generated by independently permuting off-diagonal destination labels within each true-class row.
- The null preserves each class row's distribution and norm but destroys shared cross-class destination geometry.
- Predeclared positive evidence required BOTH residual objects to have some rank `r<=10` with permutation `p<=.05` on all three statistics.

## Result
The evidence rule passes for both residual objects at every tested rank `r in {1,2,3,5,10}`.
The smallest attainable permutation p-value with 300 null draws is `1/301 = 0.003322`, and all three statistics achieve this value for both matrices.

### Soft probability leakage — unweighted
- effective rank CAL = 8.3655; TEST = 7.3480.
- rank 1 explains 52.18% of CAL energy.
- the CAL rank-1 direction explains 55.80% of TEST residual energy.
- CAL/TEST rank-1 right-subspace overlap = 0.99336.
- rank 5 explains 76.88% CAL and transfers 77.25% TEST energy.
- rank 10 explains 86.51% CAL and transfers 85.79% TEST energy.

Rank-1 null 95% thresholds:
- CAL energy: 0.3060 versus observed 0.5218.
- CAL->TEST transfer: 0.3138 versus observed 0.5580.
- subspace overlap: 0.9637 versus observed 0.9934.

### Hard confusion leakage — unweighted

- the CAL rank-1 direction explains 35.57% of TEST hard-confusion energy.
- CAL/TEST rank-1 right-subspace overlap = 0.95922.
- rank 5 explains 62.31% CAL and transfers 63.86% TEST energy.
- rank 10 explains 77.05% CAL and transfers 74.47% TEST energy.

Rank-1 null 95% thresholds:

## Robustness
The same qualitative result holds under:
- support weighting by class sample size;
- row-unit normalization that removes class-wise residual magnitude differences.

Thus the result is not explained only by head classes or by a few intrinsically difficult classes having larger residual norms.

## Interpretation
Within the Helena distribution, the residual error after the frozen A-E system is not an unstructured 100-class error field. A small number of shared destination/error directions account for a large and reproducible fraction of both probabilistic leakage and hard confusion, and the CAL factors reappear on an untouched random TEST split.

This is empirical identification evidence for a low-dimensional latent residual geometry. It is not a theorem of external-domain invariance: CAL and TEST are random splits from the same Helena population.
